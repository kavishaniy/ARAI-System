## ⚡ Fast Track Setup (For Impatient People)

If you want to skip reading and just do it:

1. Go to https://render.com
2. Sign up with GitHub
3. New Web Service
4. Select ARAI-System repo
5. Configure:
   - Name: `arai-backend`
   - Build: `pip install -r backend/requirements.txt`
   - Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - Plan: Starter ($7/month)
6. Add env vars from `backend/.env.render`
7. Click Create
8. Wait 5 minutes
9. Copy Public Domain URL
10. Go to Vercel → Update `REACT_APP_API_URL`
11. Done! ✅

(Still recommended you read a guide though!)
