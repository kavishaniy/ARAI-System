## 🔑 Key Information At a Glance

### **What Is It?**
A system that analyzes Figma design projects and provides:
- Individual analysis for each screen
- Accessibility, readability, and visual hierarchy metrics
- Specific issues and recommendations
- ARAI score (0-100) with grade (A-F)

### **How to Use It?**
1. Open ARAI → Figma Analysis
2. Paste Figma URL
3. Click "Analyze All Screens"
4. Wait 2-5 minutes
5. View results

### **Architecture in One Sentence**
Frontend sends Figma URL to backend → Backend extracts all frames from Figma → Analyzes each frame → Returns results → Frontend displays in card grid
