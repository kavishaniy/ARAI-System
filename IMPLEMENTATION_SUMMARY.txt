HOW IT WORKS:
═════════════════════════════════════════════════════════════════════════════════

1️⃣  USER CLICKS "FIGMA ANALYSIS" IN SIDEBAR
    → Navigates to /figma-analysis page

2️⃣  USER ENTERS CREDENTIALS
    → Figma API token (from figma.com/settings)
    → Figma project URL (from browser)

3️⃣  SYSTEM FETCHES FRAMES
    → Connects to Figma API
    → Extracts all frames with thumbnails
    → Displays in selectable grid

4️⃣  USER SELECTS FRAMES
    → Multi-select checkboxes
    → Preview grid with frame names/sizes
    → Select All / Clear buttons
    → Auto-selects first 5 frames

5️⃣  SYSTEM ANALYZES FRAMES
    → Exports each frame as image
    → Runs 3 analyses on each frame
    → Calculates scores (0-100)

6️⃣  RESULTS DISPLAYED
    → Overall score
    → Per-metric breakdown
    → Frame-by-frame details
    → Clear visual presentation


ANALYSIS OUTPUT:
═════════════════════════════════════════════════════════════════════════════════

Overall Score: 0-100 (combination of 3 metrics)

Per-Metric Scores:
  • Accessibility: 0-100 (WCAG compliance)
  • Readability: 0-100 (Text & typography)
  • Attention: 0-100 (Visual hierarchy)

Per-Frame Breakdown:
  • Frame name
  • Individual scores
  • Detailed metrics
  • Issues and recommendations
