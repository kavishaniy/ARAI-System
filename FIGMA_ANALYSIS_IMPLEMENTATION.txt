🎯 THREE-STEP WORKFLOW:

Step 1: Input Figma Credentials
   - User enters Figma API token
   - User enters Figma project URL
   - System validates inputs

Step 2: Select Frames
   - System fetches all frames from project
   - Shows frame grid with thumbnails
   - User selects frames to analyze
   - Auto-selects first 5 for convenience

Step 3: View Results
   - System analyzes each frame
   - Runs: Accessibility, Readability, Attention analysis
   - Shows overall score + per-frame breakdown
   - Uses existing SimplifiedAnalysisResults component

📊 METRICS ANALYZED:

Per Frame:
- Accessibility (WCAG): contrast, legibility, structure
- Readability: fonts, line lengths, hierarchy
- Attention: visual balance, focal points, flow

Overall:
- Average score across all frames
- Per-metric breakdown
- Total frames analyzed
