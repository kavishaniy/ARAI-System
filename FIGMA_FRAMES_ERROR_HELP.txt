FIGMA FRAMES ERROR - TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════

ERROR: "Failed to fetch Figma file: 404"
MEANS: The Figma API cannot find the file with the ID we extracted

POSSIBLE CAUSES:
1. ❌ Invalid Figma API token
2. ❌ Token has expired
3. ❌ Token doesn't have permission to access this file
4. ❌ File ID extracted incorrectly
5. ❌ Figma project is private/not accessible

═══════════════════════════════════════════════════════════════════

HOW TO DEBUG:
═════════════════════════════════════════════════════════════════════

1. OPEN BROWSER DEVELOPER CONSOLE (F12 or Cmd+Option+I)

2. GO TO CONSOLE TAB

3. TRY THE FIGMA ANALYSIS AGAIN

4. LOOK FOR THESE MESSAGES:

   ✓ "Extracted Figma File ID: dEDYQxZFl9JeaFx4vaPqrh"
     → File ID extraction is working

   ✓ "📤 Sending Figma frames request:"
     → Shows the file ID being sent to backend
     → Shows the API URL

   ✓ "✅ Response received:"
     → Request was successful

   ✗ "Error fetching frames:"
     → Request failed - check the error message

═══════════════════════════════════════════════════════════════════

STEP-BY-STEP FIX:
═════════════════════════════════════════════════════════════════════

STEP 1: VERIFY YOUR FIGMA TOKEN

Go to https://www.figma.com/settings
Check if your token is still valid:
  ✓ Should start with "figd_"
  ✓ Should be long (40+ characters)
  ✓ Check expiration date if shown

ACTION: If expired or invalid, create a NEW token

STEP 2: VERIFY YOUR FIGMA PROJECT URL

Your URL: https://www.figma.com/design/dEDYQxZFl9JeaFx4vaPqrh/Athlon_Redesign
File ID: dEDYQxZFl9JeaFx4vaPqrh

Make sure:
  ✓ You can access this project in Figma (log in and visit URL)
  ✓ Project is not private or restricted
  ✓ Project has at least one FRAME (not just components)

ACTION: If you can't access it, the token doesn't have permission

STEP 3: TEST WITH A SIMPLE PROJECT

If your current project doesn't work:
  1. Create a new simple Figma file
  2. Add a single FRAME with a simple rectangle
  3. Copy that file's URL
  4. Try analyzing it

This confirms if it's a token issue or project issue

STEP 4: CHECK YOUR FIGMA TOKEN PERMISSIONS

Your token needs:
  ✓ file:read (read access to files)
  ✓ file_content:read (read file content)

When creating token, ensure these scopes are checked

═══════════════════════════════════════════════════════════════════

COMMON MISTAKES:
═════════════════════════════════════════════════════════════════════

❌ MISTAKE 1: Using old/expired token
   FIX: Create a fresh token at https://figma.com/settings

❌ MISTAKE 2: Project is private
   FIX: Make sure the Figma file is accessible to your account

❌ MISTAKE 3: Token doesn't have proper permissions
   FIX: Create new token with file:read + file_content:read scopes

❌ MISTAKE 4: File has no frames (only components)
   FIX: Add at least one FRAME to the file

❌ MISTAKE 5: Using old Figma file format
   FIX: Your URL format is correct, but ensure file exists

═══════════════════════════════════════════════════════════════════

WHAT EACH PART OF THE URL MEANS:
═════════════════════════════════════════════════════════════════════

URL: https://www.figma.com/design/dEDYQxZFl9JeaFx4vaPqrh/Athlon_Redesign

  https://www.figma.com/design/
    → This is always the same

  dEDYQxZFl9JeaFx4vaPqrh
    → FILE ID (what we extract and send to API)
    → This is unique to your project

  /Athlon_Redesign
    → Project name (not used, just for humans)

  ?node-id=0-1&t=...
    → Query parameters (not used, we remove these)

FILE ID EXTRACTION LOGIC:
  1. Split by "/design/"
  2. Take the second part: "dEDYQxZFl9JeaFx4vaPqrh/Athlon_Redesign?..."
  3. Split by "/" and take first part: "dEDYQxZFl9JeaFx4vaPqrh"
  4. Split by "?" and take first part: "dEDYQxZFl9JeaFx4vaPqrh"
  5. Result: "dEDYQxZFl9JeaFx4vaPqrh" ✓
