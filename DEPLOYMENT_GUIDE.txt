FIGMA ANALYSIS - QUICK DEPLOYMENT GUIDE
========================================

🚀 DEPLOYMENT CHECKLIST:

Backend Deployment:
-------------------
1. Update requirements.txt
   ✅ DONE: httpx==0.25.2 and requests==2.31.0 added

2. Restart your backend service
   $ systemctl restart arai-backend
   OR
   $ python -m uvicorn app.main:app --reload (development)

3. Verify API is working:
   $ curl http://localhost:8000/api/v1/figma/frames
   Should return 401 (auth required) - this is correct

Frontend Deployment:
-------------------
1. Build frontend
   $ cd frontend
   $ npm run build

2. Deploy to Vercel (or your hosting)
   $ vercel deploy
   OR upload the build/ folder to your hosting

3. Verify the sidebar shows "Figma Analysis"
   Navigate to https://your-domain.com/dashboard
   Should see "Figma Analysis" with Zap icon in sidebar

📋 WHAT TO TEST IMMEDIATELY:

1. ✅ Sidebar shows "Figma Analysis" option
2. ✅ Can navigate to /figma-analysis route
3. ✅ Form displays correctly
4. ✅ Can input Figma API token
5. ✅ Can input Figma project URL
6. ✅ "Load Figma Project" button works
7. ✅ Frames appear in grid
8. ✅ Can select/deselect frames
9. ✅ Analyze button works
10. ✅ Results display correctly

⚠️ TROUBLESHOOTING:

Issue: "Module not found: figma" in backend
Solution: Run pip install httpx requests

Issue: 401 error on /figma/frames endpoint
Solution: This is normal - ensure you're sending Authorization header with JWT token

Issue: Frames not loading from Figma
Solution: Check that:
  - Figma API token is valid
  - Figma project URL is correct
  - Project has at least one frame
  - Network connection is stable

Issue: "Figma Analysis" not in sidebar
Solution: 
  - Clear browser cache
  - Rebuild frontend: npm run build
  - Restart dev server

Issue: Timeout on large projects
Solution: Projects with 100+ frames may take 5+ minutes. This is expected.

🔑 IMPORTANT NOTES:

1. Users must have a Figma account to use this feature
2. Users need to create a personal access token in Figma settings
3. Token is NOT stored - only used for current session
4. Analysis requires ~30-60 seconds per 5 frames
5. Works best with projects 5-50 frames

📱 TESTING WITH YOUR FIGMA PROJECT:

1. Go to https://figma.com/settings/tokens
2. Create a new personal access token
3. Copy your project URL from browser
4. Go to /figma-analysis in your ARAI app
5. Paste token and URL
6. Click "Load Figma Project"
7. Select frames
8. Click "Analyze Selected Frames"
9. Check results

✨ FINAL VERIFICATION:

After deployment, verify:
  ✅ Backend logs show: "🔍 Starting analysis of X frames from Figma"
  ✅ Frontend shows loading spinner during analysis
  ✅ Results page displays after completion
  ✅ Overall scores and metrics are visible
  ✅ No errors in console (F12)
