# 🔍 Search Bar - Quick Reference

## What's New?

A **search bar** on the History page that filters your analyses in real-time.

---

## Where is it?

**Location:** At the top of the History page, below the title

```
Analysis History
View all your previous design analyses and results

🔍 Search by design name or filename...
```

---

## How to Use

### 1. **Search**
- Click the search box
- Start typing (e.g., "homepage", "design", "landing")
- Results filter instantly

### 2. **View Results**
- See matching analyses below
- Result count shows how many match
- All analysis features still work (View Results, Delete, etc.)

### 3. **Clear**
- Click the **X** button to clear search
- Or delete text manually
- All analyses reappear

---

## Examples

| Search | Result |
|--------|--------|
| "homepage" | Shows all designs with "homepage" in name |
| "logo" | Shows analyses for logo designs |
| ".png" | Shows all PNG file uploads |
| "mobile" | Shows analyses for mobile designs |
| "xyz" | "No results found" message |

## Tips & Tricks

💡 **Tip 1:** Search is case-insensitive (ABC = abc)  
💡 **Tip 2:** Partial matches work ("home" finds "homepage")  
💡 **Tip 3:** Search both name and filename  
💡 **Tip 4:** No results? Try different search term  
💡 **Tip 5:** Clear button only shows when searching  

---

## No Results?

If you see "No results found":
1. Check your search term spelling
2. Try a shorter search (e.g., "home" instead of "homepage")
3. Click "Clear Search" to see all items
4. If you have no analyses, upload one first
