# ⚡ Vercel Deployment - Ultra Quick Start (5 Minutes)

> **For people who just want to get it done!**

---

## 🎯 5-Minute Express Setup

### 1️⃣ Create Account (1 min)
```
1. Go to https://vercel.com
2. Click "Sign Up"
3. Choose "Continue with GitHub"
4. Authorize & confirm email
```

### 2️⃣ Add Project (1 min)
```
1. Click "Add New..." → "Project"
2. Click "Continue with GitHub"
3. Select "ARAI-System" repo
4. Click "Import"
```

### 3️⃣ Configure (1 min)
```
Set these fields:
- Root Directory: ./frontend
- Build Command: npm run build
- Output: build
```

### 4️⃣ Environment Variable (1 min)
```
Click "Add New" and enter:
- Name: REACT_APP_API_URL
- Value: https://arai-system-production.up.railway.app/api/v1
- Check: ✓ Production  ✓ Preview  ✓ Development
```

### 5️⃣ Deploy (1 min)
```
1. Scroll to bottom
2. Click "Deploy"
3. Wait 2-5 minutes
4. Click "Visit"
5. 🎉 LIVE!
```
