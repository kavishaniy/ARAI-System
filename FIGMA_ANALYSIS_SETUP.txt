# Figma Analysis Feature - Implementation Guide

## Overview
A complete Figma design analysis feature has been integrated into the ARAI web app. Users can now upload their Figma project links and analyze all frames for accessibility, readability, and visual attention patterns.

## ✅ What's Been Implemented

### Frontend Components (React)

1. **FigmaAnalysis.jsx** (`/frontend/src/pages/FigmaAnalysis.jsx`)
   - Main page component that orchestrates the 3-step analysis flow
   - Manages state for: project data, selected frames, and results
   - Includes back navigation between steps
   - Integrated with Sidebar for navigation

2. **FigmaProjectInput.jsx** (`/frontend/src/components/Analysis/FigmaProjectInput.jsx`)
   - Step 1: User input for Figma API token and project URL
   - Complete authentication guide for obtaining Figma API tokens
   - Form validation for inputs
   - Security notes about token handling
   - Beautiful, responsive UI with helpful instructions

3. **FigmaFramesAnalysis.jsx** (`/frontend/src/components/Analysis/FigmaFramesAnalysis.jsx`)
   - Step 2: Frame selection and management
   - Displays all frames from the Figma project in a grid
   - Frame preview thumbnails
   - Multi-select functionality with Select All/Clear buttons
   - Shows frame dimensions and metadata
   - Auto-selects first 5 frames for convenience
   - Analyze button with loading state

4. **Updated App.jsx**
   - Added new route: `/figma-analysis`
   - Imported FigmaAnalysis component
   - Route is protected (requires authentication)

5. **Updated Sidebar.jsx**
   - Added "Figma Analysis" navigation item with Zap icon
   - Available in main navigation after Dashboard

6. **figma.js Service** (`/frontend/src/services/figma.js`)
   - Helper functions for Figma API calls
   - `getFrames()`: Fetch frames from project
   - `analyzeFrames()`: Send frames for analysis

### Backend API (Python/FastAPI)

1. **figma.py** (`/backend/app/api/figma.py`)
   - Complete Figma integration module
   - Two main endpoints:

   **POST /api/v1/figma/frames**
   - Fetches all frames from a Figma project file
   - Input: file_id, figma_token
   - Output: List of frames with metadata
   - Error handling for invalid credentials

   **POST /api/v1/figma/analyze**
   - Analyzes selected frames using ARAI analyzers
   - Input: file_id, figma_token, frames list, project_url
   - Runs three analyses on each frame:
     - **Accessibility (WCAG)**: Contrast, text legibility, semantic structure
     - **Readability**: Font sizes, line lengths, text hierarchy
     - **Attention**: Visual hierarchy, focal points, balance
   - Output: Detailed results per frame + overall scores
   - Features:
     - Async frame export from Figma
     - Lazy-loaded analyzers (memory efficient)
     - Per-frame error handling
     - Overall score calculation

2. **Figma API Helper Class**
   - `FigmaAPI` class for Figma API interactions
   - Methods:
     - `get_file()`: Fetch file metadata
     - `get_frame_image()`: Export frame as PNG
   - Proper error handling and logging

3. **Frame Extraction**
   - Recursive document traversal to find frames
   - Extracts: ID, name, type, dimensions
   - Supports FRAME, COMPONENT, and COMPONENT_SET node types

4. **Updated main.py**
   - Imported figma router
   - Registered router with prefix `/api/v1`
   - Tagged as 'figma' for API documentation

### Dependencies Added
- **httpx** (0.25.2): Async HTTP client for Figma API
- **requests** (2.31.0): HTTP requests library

## 🔄 Analysis Flow

1. **User enters Figma credentials**
   - Figma API token
   - Project URL (e.g., https://www.figma.com/file/...)

2. **System fetches frames**
   - Connects to Figma API
   - Extracts all frames with thumbnails and metadata
   - Displays in selectable grid

3. **User selects frames to analyze**
   - Multi-select with checkboxes
   - Quick actions: Select All, Clear
   - Shows selection count

4. **Analysis runs**
   - Exports each frame from Figma
   - Runs 3 analyses per frame:
     - WCAG Accessibility
     - Readability
     - Attention/Visual Hierarchy
   - Calculates overall scores
   - 5-minute timeout for large projects

5. **Results displayed**
   - Uses existing SimplifiedAnalysisResults component
   - Shows per-frame breakdown
   - Overall score and metrics
   - Detailed insights for each metric

## 🔐 Security Considerations

- Figma tokens are **not stored** on the server
- Tokens are transmitted only via HTTPS
- User instructions clearly state to keep tokens confidential
- Tokens can be revoked anytime in Figma settings
- No user data is stored beyond the analysis session

## 📊 Analysis Metrics

Each frame is analyzed for:

### Accessibility (WCAG Compliance)
- Color contrast ratios
- Text legibility
- Element spacing
- Component structure

### Readability
- Font sizes and weights
- Line lengths
- Text hierarchy
- Line spacing

### Attention/Visual Hierarchy
- Visual balance
- Focal points
- Hierarchy depth
- Visual flow

## 🚀 How to Use

### For Users:

1. Click "Figma Analysis" in the sidebar
2. Enter your Figma API token:
   - Go to figma.com/settings
   - Create a personal access token
   - Copy and paste in the form
3. Enter your project URL (copy from browser)
4. Click "Load Figma Project"
5. Select frames you want to analyze (or use Select All)
6. Click "Analyze Selected Frames"
7. View detailed analysis results

### For Developers:

#### Backend Setup:
```bash
# Install dependencies
pip install -r requirements.txt

# Figma API is available at:
# POST /api/v1/figma/frames
# POST /api/v1/figma/analyze
```

#### Frontend Build:
```bash
npm install
npm start
# or for production:
npm run build
```

## ⚠️ Known Limitations

1. Large projects (100+ frames) may take longer to analyze
2. Figma exports are rendered at 2x scale for quality
3. Some complex Figma features (masks, effects) may not render perfectly
4. Token must be valid; expired tokens show clear error
5. Analysis is sequential per frame (not parallel) for stability

## 📝 Error Handling

The system provides clear error messages for:
- Invalid Figma URLs
- Expired/invalid tokens
- Network connection issues
- Frame export failures
- Analysis timeouts
- Missing frames in project
