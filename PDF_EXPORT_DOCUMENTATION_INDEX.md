## 🎯 Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
cd frontend
npm install jspdf html2canvas --save
```

### Step 2: Upload Designs
- Use the upload interface
- Select design images
- Wait for analysis

### Step 3: Export
- Click "📥 Export as PDF"
- Choose format
- Download automatically

**Done!** 🎉
